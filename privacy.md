# Gog CLI privacy policy

Gog CLI is used only by its owner, Christian Burke, to access his own Google accounts.

- Data from Google APIs (Gmail, Drive, Calendar) is read and changed only on the owner's own computer.
- It is not shared with anyone, sold, or used for advertising.
- OAuth tokens are stored in the macOS Keychain on that computer.
- Access can be revoked at any time at https://myaccount.google.com/permissions

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions go to the support email shown on the app's Google sign-in screen.
